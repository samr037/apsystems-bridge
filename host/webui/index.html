Label is the human-friendly name shown on cards, in charts and in Home Assistant — spaces and accents OK. The identifier is auto-derived from the label (slug-only) and locked once the inverter exists, so MQTT topics and HA entities stay stable when you rename. Family is auto-detected from the serial prefix (4080→YC600, 5010→QS1, 7040→DS3).

throttle calib — signed watt offset applied to set-power commands (effective = requested + calib). Leave 0 unless the inverter throttles off-target; e.g. a DS3 capped at 150 W settles ~11% high, so calib ≈ −17 brings it on target.

adding an inverter — quick guide

Two pieces of info are required and one is optional — the serial is printed on the unit, and the short address can be left blank and filled in later.

  1. 1 Find the inverter's serial number. It's printed on the side of the unit (12 hex characters). For YC600 it starts with 408000; QS1 with 501000; DS3 with 704000.
  2. 2 Optionally — set the on-air short address. Each inverter has a 2-byte short address (e.g. 0xABCD). If you already know it, enter it here; otherwise leave it blank and add it later — polling won't start until it's set.
  3. 3 Click + add inverter and fill the form. Family auto-detects from the serial. The web UI writes /opt/aps/etc/inverters.json; the daemon hot-reloads it within the next 30-second poll cycle and starts trying to reach the new inverter.
  4. 4 Check the NOW tab. If the inverter is paired & responsive, it'll show up LIVE within a cycle. If short addr is missing, you'll see NO DATA until you fill it in.
