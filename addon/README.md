# APsystems Open Bridge — Home Assistant add-on

Polls APsystems **YC600 / DS3** solar micro-inverters directly over their
2.4 GHz radio link and publishes live telemetry to MQTT — no APsystems
ECU and no cloud account.

Requires a Sonoff ZBDongle-P (CC2652P) flashed with this project's
firmware, plugged into the Home Assistant host and within radio range of
the inverters.

See [DOCS.md](DOCS.md) for setup.
